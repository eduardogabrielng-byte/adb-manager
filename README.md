# ADB Manager

A lightweight Python-based Android device manager that uses ADB over TCP/IP to capture screenshots, record screens, and transfer files remotely.

## Features

- 📸 Take screenshots remotely
- 🎥 Record the device screen
- 📤 Upload files to the device
- 📥 Download files from the device
- 📡 Connect through ADB over a network
- 🔄 Easily switch between devices

## Requirements

- Python 3.12+
- Android Debug Bridge (ADB)
- Android device with USB Debugging enabled
